### 実装への注意

- UIの文字・数字・カウンター・グラフは画像にせず HTML/CSS/JS で実装。
- これらの素材は画像化されたモデルUIからの抽出物で、源泉は高解像度の個別原画ではありません。元のレトロな画素表現を維持するため、CSSで等倍または整数倍率の拡大を推奨します。
- 花弁・猫・入場者・赤煉瓦は抽出精度が比較的良好。小型の単色アイコンは淡色の縁に多少の残留マットが残る場合があります。
- デザイン検収を優先しており、GitHubへのアップロード・Web実装・Pages検証はこの素材書き出しに含めていません。

装飾用の光線は元モデルではボタン輪郭と接しており、きれいに切り出せないため採用しませんでした。
