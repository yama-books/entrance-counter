## 利用する操作

1. 上部「入場者数予測」：本日・2日間の見込み。「予測を入力」で現在の担当名を転記したフォームから人数を保存。編集可能。名前・対象日・人数・時刻を記録し、保存後だけ前に保存された予測を表示する。再表示時は履歴を隠す（本人認証ではない）。
2. 「山本を呼ぶ」：現在の担当名を編集可能な欄へ転記。入力必須・合言葉設定・GAS送信先は維持。
3. 下部「終了・結果」：「1日目終了」「2日目終了」を確認付きで確定。ボタンは確定後「確定解除」に変わり、解除後に再び追加/取消ができる。確定・解除は追記履歴。2日目終了後は合計人数・赤煉瓦数を表示。
4. 2日目の各カウンター下に2日間累計。下部「前日の記録」で1日目の記録と結果を閲覧。
5. グラフの「2日通算」：2日間の同時刻帯を合算し、若草の入場・煉瓦色の赤煉瓦を横並びで表示。共通目盛り・棒の数値・タップ時の両数値を使う。通常タブは当日の片方の表示。

対象日はレジ同様の2026/10/31・11/1、各日9:00〜16:30。金額は扱わず人数・冊数とする。

## 保存と互換性

既存受付イベント形式・ストア・シフト画像を保持。予測/終了履歴は別キーで保存し、JSONに追加フィールドとして含める。受付記録CSVと予測CSVを用意。JSONは同じ読取トランザクションのスナップショット。古いJSONで既存予測や終了履歴を消さない。

確定中の追加・取消・結果を変える復元は保存処理でも拒否。確認中に件数が変わった場合は確定を拒否し、再確認を求める。解除すれば再開できる。DB1→2で既存ストアを保持して更新し、旧版のDB1接続を拒否する。旧コードへ戻して使用しない。実際の受付記録・入力担当者名・メモ・合言葉はGitHubやActionsへ保存していない。
