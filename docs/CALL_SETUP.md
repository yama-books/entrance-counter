# 「山本を呼ぶ」メール通知の設定

## 仕組み

図書館受付と古本市レジは共通のGASウェブアプリを使う。GASの公開デプロイURLは両アプリに組み込み済み。**利用者がURLを入力する必要はない**。GASの認証用合言葉は端末内のlocalStorageとGASのスクリプトプロパティだけに保存し、GitHubへ含めない。

送信先アドレスはGASのスクリプトプロパティ `RECIPIENT`、合言葉は `PASSCODE`。公開リポジトリにアドレス・合言葉・実際の要件を保存しない。

## iPadでの初期設定（各端末で一度）

1. [図書館受付](https://yama-books.github.io/entrance-counter/)をSafariで開く。
2. 画面下部「設定」→「メール通知」にある「合言葉」に、GAS側の `PASSCODE` と同じものを入力し、「合言葉を保存」。
3. 「山本を呼ぶ」を開き、**担当者名（1〜80文字・必須）**と**要件（1〜500文字・必須）**を入力して送信する。
4. メールが届くかを確認する。**送信失敗時は両方の入力が残り、自動再送しない**。画面が失敗表示でも受信済みの可能性があるため、再送前に着信を確認する。

古本市レジも同じGASを使い、別のiPadでは「設定」→「メール通知」で合言葉を1回入力する。パスコードはURLには入れない。

以前のアプリが端末内に保存したGAS URLは**無視**し、固定のデプロイ先を使う。合言葉だけを引き継ぐ。設定ファイルの読み書きは不要になったため、画面から撤去した。

## 件名・GASの更新

- 図書館受付：`【図書館受付より】山本を呼ぶ`。JSONの `source` は `library`。
- 古本市レジ：`【古本市レジより】山本を呼ぶ`。JSONの `source` は `book-sale`。

アプリからは `key`、`text`、`staff`（入力された担当者名）、`source`、`at` を `text/plain` POSTのJSONで送る。両アプリの合計で20秒に1回・JST日付で1日50回の送信制限。

**注意：GitHubでGASコードを更新しても、稼働中のGASは更新されない。** 現在稼働しているGASプロジェクトへリポジトリの [gas/call-staff.gs](../gas/call-staff.gs) を貼り直し、「デプロイ」→「デプロイを管理」→既存デプロイを編集→「新バージョン」で更新する。**新しいデプロイを作らず、URLを維持する。** スクリプトプロパティは変更しない。

## 検証上の区別

既存の本番メール到達はユーザー報告による。**固定URL版の画面、必須担当者名、新しい件名での実機送信・着信は別途確認すること。** 模擬応答のテストを実際のGAS送信検証と混同しない。
