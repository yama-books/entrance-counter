# 「山本を呼ぶ」メール送信の設定

「山本を呼ぶ」ボタンは、iPadで入力した要件を Google Apps Script（以下GAS）のウェブアプリへ送り、GASがメールを送信する。

- 宛先メールアドレスと合言葉は **GASのスクリプト プロパティだけ** に保存する。このリポジトリ・Actions・Pagesには置かない。
- iPadには、ウェブアプリのURLと合言葉を端末内（localStorage）にだけ保存する。
- GASは合言葉が一致したときだけ送信し、20秒に1通・1日50通までに制限する。

## 1. GASを用意する（送信元のGoogleアカウントで1回）

1. https://script.google.com で「新しいプロジェクト」を作る。名前は例えば「entrance-counter-call」。
2. `コード.gs` の中身を、このリポジトリの [gas/call-staff.gs](../gas/call-staff.gs) の内容に置き換えて保存する。
3. 左の「プロジェクトの設定」→「スクリプト プロパティ」で次の2つを追加する。
   - `RECIPIENT`：送信先メールアドレス
   - `PASSCODE`：推測されにくい合言葉（iPadにも入力する）
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Googleの許可画面でメール送信の権限を許可する。
6. 表示された「ウェブアプリ URL」（`https://script.google.com/macros/s/…/exec`）を控える。

GASのコードを変えたときは「デプロイを管理」から同じデプロイの新しいバージョンを作る。URLは変わらない。

## 2. iPadに設定する

1. アプリの「山本を呼ぶ」を押す。
2. 「送信設定（この端末だけに保存）」を開き、ウェブアプリURLと合言葉を入力して「設定を保存」。
3. 要件を入力して「山本を呼ぶ（メール送信）」を押し、メールが届くことを確認する。

送信に失敗したときは入力した要件が残る。Safariのサイトデータを消去すると送信設定も消えるため、もう一度入力する。

## 確認状況

- ブラウザ試験では送信先を模擬応答に差し替えて、送信内容・成功表示・失敗時の要件保持・設定の検証を確認する。
- 実際のGASデプロイとメール着信、iPad Safari実機での送信は、GASを設定した後に確認する（未確認）。

## 3. 複数端末に同じ設定を入れる（共通ファイル）

2つのアプリは同じ `https://yama-books.github.io` という配信元にあるため、**同じ端末・同じSafariであれば**、入場カウンター側の保存設定を古本市レジからも使える。別端末のSafariへは自動同期されない。

- 設定済みの端末で「山本を呼ぶ」→「送信設定」→「共通設定ファイルを書き出す」。`staff-call-settings.local.json` がダウンロードされる。
- そのファイルをAirDropや限定共有のiCloud Driveなどで、別の管理端末へ安全に渡す。
- 別端末でどちらかのアプリを開き、「送信設定」→「共通設定ファイルを読み込む」から選択。読み込めば以降は端末内に保存され、両アプリで利用可能。
- **このファイルにはGAS URLと合言葉がそのまま含まれる。公開GitHub・Issue・PR・公開サイト・チャットには掲載しないこと。** 使用後は共有先とコピーを管理すること。

Safariはセキュリティ上、利用者が選択していない端末内ファイルをWebアプリから自動的に読み取れない。Publicな静的JSONに合言葉を置いて自動取得させる設計は採用しない。

## 4. 件名を両アプリで分けるためのGAS更新

2026-10-30時点でGASの件名を `【図書館受付より】山本を呼ぶ` と `【古本市レジより】山本を呼ぶ` に分岐する仕様とした。送信JSONの `source` は図書館側が `library`、古本市レジ側が `book-sale`。旧版の古本市レジの `staff: 古本フリマレジ` も認識する。

**GitHub上のGASコードを変えるだけではデプロイ済みのGASは変わらない。** GAS編集画面のコードを最新 `gas/call-staff.gs` に差し替え、「デプロイ」→「デプロイを管理」→既存デプロイを編集→「新バージョン」で更新する。既存URL・端末設定はそのまま使用できる。既に利用しているGASのスクリプトプロパティは消さない。

共有GASを利用した場合、20秒の送信間隔と日次50通上限は**両アプリの合計**で管理する。日次の回数はスクリプトプロパティでJST日付ごとに保持する。古いGASデプロイの挙動は実更新まで変わらない。
