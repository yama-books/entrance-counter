# 「山本を呼ぶ」メール送信の設定

「山本を呼ぶ」ボタンは、iPadで入力した要件を Google Apps Script（以下GAS）のウェブアプリへ送り、GASがメールを送信する。

- 宛先メールアドレスと合言葉は **GASのスクリプト プロパティだけ** に保存する。このリポジトリ・Actions・Pagesには置かない。
- iPadには、ウェブアプリのURLと合言葉を端末内（localStorage）にだけ保存する。
- GASは合言葉が一致したときだけ送信し、20秒に1通・1日50通までに制限する。

## 1. GASを用意する（送信元のGoogleアカウントで1回）

1. https://script.google.com で「新しいプロジェクト」を作る。名前は例えば「entrance-counter-call」。
2. `コード.gs` の中身を、このリポジトリの [gas/call-staff.gs](../gas/call-staff.gs) の内容に置き換えて保存する。
3. 左の「プロジェクトの設定」→「スクリプト プロパティ」で次の2つを追加する。
   - `RECIPIENT`：送信先メールアドレス
   - `PASSCODE`：推測されにくい合言葉（iPadにも入力する）
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Googleの許可画面でメール送信の権限を許可する。
6. 表示された「ウェブアプリ URL」（`https://script.google.com/macros/s/…/exec`）を控える。

GASのコードを変えたときは「デプロイを管理」から同じデプロイの新しいバージョンを作る。URLは変わらない。

## 2. iPadに設定する

1. アプリの「山本を呼ぶ」を押す。
2. 「送信設定（この端末だけに保存）」を開き、ウェブアプリURLと合言葉を入力して「設定を保存」。
3. 要件を入力して「山本を呼ぶ（メール送信）」を押し、メールが届くことを確認する。

送信に失敗したときは入力した要件が残る。Safariのサイトデータを消去すると送信設定も消えるため、もう一度入力する。

## 確認状況

- ブラウザ試験では送信先を模擬応答に差し替えて、送信内容・成功表示・失敗時の要件保持・設定の検証を確認する。
